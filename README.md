# Forest Treasures Prototype (95)

Create a polished responsive website prototype for a Russian premium forest-food brand called «Лесные устрицы».

The website should present the brand as a personal/family brand of Андрей Ильич Егоров, who has been collecting and processing wild forest mushrooms and other forest products for many years.

IMPORTANT:
This is version 0.1 of the website. It is a visual and functional prototype that will be filled with real photographs, final texts, real prices, availability, reviews and contact information later.

Do NOT invent facts, certifications, awards, customer reviews, delivery services, store locations or production claims that are not provided.

Brand positioning

The brand is built around:

wild forest mushrooms and forest products;

personal experience and knowledge of the forest;

predominantly own harvesting of raw materials;

careful selection and processing;

the northern part of Leningrad Region;

the village of Vinnitsy;

Vepsian cultural region / Vepsky Forest;

quality as the main brand value;

personal contact with customers.

The website should NOT position the business as:

a restaurant supplier;

a HoReCa supplier;

an industrial wholesale supplier;

a mass-market grocery store;

a large marketplace.

The primary audience is affluent private customers aged 30+ from Moscow and Saint Petersburg.

The website is primarily an image-building website + product catalogue + information about purchasing.

Visual direction

Create an elegant, classic-premium, natural visual identity.

Use the existing packaging as a visual reference.

Main visual direction:

warm yellow / cream background;

deep forest green;

light muted green;

natural beige/brown tones;

a restrained berry/magenta accent;

botanical and forest-inspired decorative elements;

stylised fir trees as a subtle recurring brand element.

The design should feel:

northern;

natural;

authentic;

elegant;

premium but not flashy;

warm;

personal;

calm.

Avoid:

rustic cliché aesthetics;

aggressive e-commerce design;

excessive luxury;

bright modern startup aesthetics;

plastic-looking AI imagery.

Use generous whitespace, large typography, editorial layouts and high-quality product presentation.

Use real-photo placeholders where actual photography is not available.

No search function is required.

Use only facts supported by the supplied information:

северный регион;

ручная работа / переработка only where phrased carefully;

quality is the main value of the brand.

Do not create fake certificates or quality badges.

UX

The website should feel like a premium editorial brand rather than a conventional online store.

Primary user journey:

Discover brand
→ understand who Андрей Егоров is
→ discover the forest and origin
→ explore products
→ learn about the signature product
→ understand how to buy
→ contact the brand

Use clear CTA buttons:

«Смотреть продукцию»
«Подробнее»
«Как купить»
«Связаться»

No online payment is required.
No shopping cart is required for this prototype.

Responsive design

The website must look polished on:

desktop;

tablet;

mobile.

Mobile navigation must be clean and easy to use.

Important implementation rule

Build the site so that all temporary content can easily be replaced later.

Use reusable components for:

product cards;

recipe cards;

review cards;

image placeholders;

navigation;

buttons.

Do not over-engineer the website.

The goal is a beautiful, premium, functional MVP prototype that can be shown to the client now and refined together later.
